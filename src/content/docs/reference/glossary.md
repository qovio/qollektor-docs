## Gruppe

Eine Organisationseinheit – z. B. ein Verein, eine Schulklasse oder ein Freundeskreis. Eine Gruppe kann mehrere Kampagnen anlegen.

## Kampagne

Eine konkrete Sammelbestellung mit Artikeln, Preisen und Frist. Teilnehmer bestellen innerhalb einer Kampagne.

## Bestellung

Die Auswahl eines einzelnen Teilnehmers innerhalb einer Kampagne.

## Zahlungsreferenz

Ein eindeutiger Code im Verwendungszweck der Überweisung, mit dem Qollektor eingehende Zahlungen einer Bestellung zuordnen kann.

## SEPA-EPC-QR-Code

Ein QR-Code-Standard des European Payments Council, der IBAN, Betrag und Verwendungszweck einer Überweisung enthält. Banking-Apps befüllen damit das Überweisungsformular automatisch.

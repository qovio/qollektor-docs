## Was ist Qollektor?

Qollektor ist eine Web-Plattform für die gesamte Lebensdauer einer Sammelbestellung: von der Kampagnenanlage über die Teilnehmerbestellungen bis zur Erzeugung individueller SEPA-Zahlungsreferenzen und der Statusverfolgung.

<CardGrid>
	<Card title="Kampagne erstellen" icon="open-book">
		Lege fest, was bestellt wird, bis wann teilgenommen werden kann und wer eingeladen ist.
	</Card>
	<Card title="Teilnehmer einladen" icon="add-document">
		Teile einen Link – Teilnehmer bestellen ohne Login direkt aus dem Browser.
	</Card>
	<Card title="SEPA-QR-Zahlung" icon="approve-check">
		Jeder Teilnehmer erhält eine eindeutige Zahlungsreferenz und einen scanbaren EPC-QR-Code.
	</Card>
	<Card title="Status verfolgen" icon="bars">
		Sieh auf einen Blick, wer bestellt und wer bereits gezahlt hat.
	</Card>
